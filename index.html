📘 Koneksi Facebook Pro

MEMERIKSA… Menyimpan…

ID Halaman FB (dapat dari → Tentang Halaman, atau via Graph API Explorer). Profil mode profesional juga didukung.

Token tersimpan di database server agar worker 24/7 bisa memposting walau browser mati. Tidak dibagikan ke pihak lain.

📖 Panduan: cara mendapatkan Access Token Facebook
  1. Buka developers.facebook.com → login → menu My Apps → Create App (tipe Business).
  2. Masuk ke Graph API Explorer (Tools → Graph API Explorer).
  3. Pilih aplikasimu, lalu di bagian Permissions tambahkan: pages_show_list, pages_manage_posts, pages_read_engagement.
  4. Klik Generate Access Token → izinkan semua.
  5. Tempel token sementara di kolom atas → klik Ambil Page Token → token halaman (berlaku lama) otomatis tersimpan di server.
  6. Salin ID Halaman dari hasil test koneksi, isi di kolom Page ID.
Catatan: Posting ke profil pribadi tidak didukung API Facebook — gunakan Halaman atau profil mode profesional (FB Pro).
☁️ Cara kerja posting otomatis 24/7
Saat kamu menjadwalkan/posting, media sudah tersimpan di server dan item antrean masuk ke database. Worker server berjalan tiap 30 detik: mengambil item jatuh tempo → membuat caption AI (jika kosong) → mengunggah ke Facebook Graph API (foto: /photos, video: /videos, Reel: 3 fase video_reels + rupload — dari server jadi tanpa kendala CORS) → mencatat hasil ke riwayat. Karena diproses di server, PC, laptop, dan browser kamu boleh dimatikan.
